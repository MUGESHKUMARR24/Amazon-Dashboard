# Amazon-Dashboard
This project analyzes an Amazon e-commerce dataset using Tableau.
It visualizes sales, products, categories, ratings, and customer-related insights.
Interactive dashboards are created to identify trends and business patterns.
The project demonstrates practical skills in data analysis and visualization.
